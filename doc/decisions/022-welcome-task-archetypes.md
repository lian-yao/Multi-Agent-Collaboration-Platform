# ADR-022: 欢迎区引导卡是「任务原型」而非功能入口

状态：已接受（2026-09-17）

## 背景

用户评价工作台主页的三个预设卡片：「ui 有点丑，文本是左置的，居中效果应该好一些」，
并给了两条出路——**删掉**，或者**改成符合「多 agent 协作平台」的内容**：

> 比如类似直接提问，这种体现单 agent 直接回答的问题，然后有一些需要搜索内容的，就经过类似
> 调查 agent、总结 agent 等等这种能够通过多 agent 完成的工作，以此来体现平台的意图识别动态调度能力。

核实原实现（`App.tsx::Welcome`）：三张卡是「图标 + 标题」的横排左对齐条目，标题就是任务示例
（「解读一篇文章」），图标靠 `>svg:first-child { width:100% }` 拉满整行、再用
`flex-wrap` 把下面的文字挤到第二行。**版式上确实是坏的**：那条规则是为另一种结构写的，
改成三段内容后没有跟着改。

更要紧的是语义问题：三张卡只说了「可以问这类问题」，**没有任何一处的文案说明这类问题会被几个
Agent、按什么形态处理**。对一个以「意图识别 + 动态调度」为核心的平台，这是主页面最大的信息缺口。

## 决策

**保留卡片，但把它的语义从「功能入口」改成「任务原型」，居中竖排，并且点下去真的切编排模式。**

- 每张卡三段：图标 / 标题（这类任务是什么）/ 协作形态（这类任务通常怎么被拆开执行）。
  三条形态分别是「通常 1 个 Agent 直答」「调查 → 分析 → 总结」「多步核对与整理」，
  形成对照才有信息量。
- 版式改竖排居中（`flex-direction:column` + `align-items:center` + `text-align:center`），
  **删掉那条把图标拉满整行的 `>svg:first-child` 规则**——它是坏版式的直接原因。
  窄屏（≤680px）摊成单列三行：三列在手机上每列约 110px，形态标签会被折成三行，反而更难读。
- **点卡片 = 填提示词 + 把编排模式切到「自动编排」**。这一条是决策的核心而不是附带便利：
  卡片上写的「调查 → 分析 → 总结」**只有在规划 Agent 真的参与判断时才成立**。只填文字不换模式，
  卡片就是在承诺一件当前链路不会做的事——属于 ADR-018 认定的同一类问题（假选择）。
- 卡片下方**显式写出当前生效的模式**（`.welcome-note`）。宁可这句提示显得啰嗦，也不要让卡片
  的承诺和当前链路对不上。

否决「删掉三张卡」：删掉之后空白欢迎页只剩一句标题，用户第一眼看不到「这个平台能做什么」，
而且用户给的另一条出路（改成体现协作形态的内容）本身就是更好的答案。

## 备选方案

- **整体删掉**。否决：欢迎页会退化成一句标题 + 一个输入框，把「多 Agent 协作」这个卖点从首屏
  拿掉。用户是把它作为备选给出的，不是要求。
- **保留原卡片只修版式（居中）**。否决：版式是次要问题，语义才是主问题。只居中仍然说不出
  这个平台和普通对话式 AI 的区别。
- **卡片只填提示词、不切模式**。否决：见决策第 3 条，这是假承诺。
- **把模式切换做成卡片上的第二个可点区域（「用这个模式」）**。否决：一个卡片里放两个动作，
  点哪儿取决于命中区域的边界，是常见的交互 bug 来源；输入区右侧已经有显式的模式开关，
  用户随时能改回来。

## 影响

- `App.tsx::Welcome` 重写；`styles.css` 的 `.suggestions` 卡片规则整段替换为 `.suggestion`
  竖排卡（并清掉 `.suggestions button`、`.suggestions button>svg:first-child` 等旧规则），
  新增 `.suggestion-icon` / `.suggestion-shape` / `.welcome .welcome-note`。
- `workspace-smoke.tsx` 增断言：卡片各自写出协作形态、点卡片同时切到自动编排、
  填提示词与设模式在同一个函数里、**旧横排规则已清理**（残留会把新卡图标撑成整宽）。
- `rendercheck/verify_preview.mjs` 在预览产物上真点一遍：三张卡在、卡片是竖排居中、
  先手动切到「固定三步」再点卡片，验证模式被切回「自动编排」——默认就是 dynamic，
  不先改一次这条断言等于没测。
- **未解决**：卡片文案是写死的三条任务原型，与后端真实的能力边界没有联动。若将来编排层
  支持的能力面变化（例如新增只读数据类角色），卡片需要人工同步。
